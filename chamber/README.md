# Jujuy Chamber of Commerce

WDD 231 student project by Jose Ezequiel Flores Menendez.

The directory uses fictional businesses and contact information. Each website link uses example.com. The chamber is based in San Salvador de Jujuy, Argentina.

Colors: dark green (#174c3c), gold (#f2d28a), and a light background (#faf8f3). Font: Roboto from Google Fonts, with Arial as a fallback.

The directory is the first page. Home, Join, and Discover links are reserved for the upcoming course assignments.

Business icons and the mountain logo were created for this project. Social icons come from Bootstrap Icons; the license is in images/bootstrap-icons-LICENSE.txt.
