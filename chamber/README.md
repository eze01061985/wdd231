# Jujuy Chamber of Commerce

WDD 231 student project by Jose Ezequiel Flores Menendez.

The directory uses fictional businesses and contact information. Each website link uses example.com. The chamber is based in San Salvador de Jujuy, Argentina.

Colors: dark green (#174c3c), gold (#f2d28a), and a light background (#faf8f3). Font: Roboto from Google Fonts, with Arial as a fallback.

Home, Directory, and Join are available. Join includes a membership form, four benefit dialogs, and an application confirmation page. Discover is reserved for an upcoming assignment.

Business icons and the mountain logo were created for this project. Social icons come from Bootstrap Icons; the license is in images/bootstrap-icons-LICENSE.txt.

The home page randomly selects three Silver or Gold members from data/members.json. Events are fictional examples.

Weather setup: enter an OpenWeatherMap key in scripts/weather-config.mjs. The current weather and 5-day/3-hour forecast endpoints are used for San Salvador de Jujuy. The page selects noon forecasts for the next three days. Live current weather and the three-day forecast were verified on November 16, 2026.
